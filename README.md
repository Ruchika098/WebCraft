# WebCraft

This repository contains the selected frontend web development project built using HTML,CSS,JavaScript, and Bootstrap.

## Selected Levels

- Level 1: HTML/CSS and JavaScript
- Level 2: Front-end Frameworks and Responsive Design

## Level 1

Includes:
- Heading, paragraph and image
- Form with input and submit button
- Navigation menu with three links
- Button that changes color when clicked
- Time-based greeting alert
- Two-number addition calculator

## Level 2

Includes:
- Responsive Bootstrap card with image and text
- Responsive Bootstrap grid
- CSS media query responsive design
- Mobile-friendly hamburger navigation

## How to Run

1. Download or clone this repository.
2. Open `Level-1/index.html` in a browser.
3. Open `Level-2/index.html` in a browser.
4. Internet access is recommended for the Bootstrap CDN and remote demo images.
